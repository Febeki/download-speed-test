# Download Speed Test

Консольный скрипт для замера скорости скачивания с заданного HTTP- или HTTPS-адреса. Он выполняет 10 последовательных GET-запросов и дочитывает тело каждого ответа перед следующим запросом.

## Запуск

Нужен Python 3.10 или новее. Скрипт использует только стандартную библиотеку.

В корне репозитория запусти команду с нужным URL. Для быстрой проверки подойдёт картинка из примера, для замера под нагрузкой укажи ссылку на файл большего размера.

```sh
python speed_test.py "https://www.python.org/static/img/python-logo.png"
```

Справка доступна через `python speed_test.py --help`.

## Результаты

- **Average request time** — среднее время одного запроса в секундах. Каждый замер длится от начала запроса до полного чтения ответа.
- **Total downloaded** — суммарный размер тел десяти ответов в байтах.
- **Download speed** — скорость в мегабитах в секунду (Мбит/с, `Mbps`). Формула `(общий объём в байтах × 8) / суммарное время в секундах / 1 000 000`.

Скорость относится к указанному ресурсу и включает время установки соединения и ожидания ответа сервера. При сбое скрипт печатает номер запроса и причину в stderr и завершается с кодом `1`.
